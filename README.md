# Экономикалық эстафета / Экономическая эстафета — 2-кезең / 2 тур

**Version 3.0 — жеңілдетілген интерфейс және әр командаға көп тапсырма.** Node.js 22 және PostgreSQL / local JSON.

## Мұғалімге арналған негізгі жаңалықтар

- **Админ-панель басты бетте көрсетілмейді.** Сайттың жоғарғы жағындағы **«ЭКОНОМИКАЛЫҚ ЭСТАФЕТА» / «ЭКОНОМИЧЕСКАЯ ЭСТАФЕТА»** атауын басқанда құпиясөз терезесі ашылады. Мұғалімнің паролін студенттерге бермеңіз.
- Әдепкіде **7 команда**, бірақ мұғалім **1–20 команда** құра алады. Әр командаға **1–30 жеке тапсырма** қосылады. Командалар бір-бірінің тапсырмасын көрмейді.
- Мұғалімнің «Тапсырмалар» бөлімінде **бір командаға жеке-жеке тапсырма** жазу немесе **көп тапсырманы бір мәтіннен (жол-жолымен) қосу** мүмкіндігі бар. **«Барлық өзгерісті сақтау»** басылмаса, өзгерістер базаға түспейді.
- Сақталған тапсырмалар студенттерге **20 сұрақтық мұғалім тесті аяқталып, мұғалім «Тапсырмаларды ашу» басқанға дейін** көрінбейді.
- Әр студент аты-жөнімен тіркеледі, өз командасын және тек сол командаға берілген PIN-кодты енгізеді.
- Әр тапсырма бойынша **командадан бір ғана ортақ жауап** қабылданады. Бірінші тіркелген студент — капитан; мұғалім «Жауаптар» бөлімінен капитанды өзгерте алады.
- **Капитан жауапты жіберген сәтте келесі дайын тапсырма автоматты түрде ашылады.** Мұғалімге сабақ ортасында жаңа тапсырма енгізудің қажеті жоқ. Жіберілген жауапты кейін өзгертуге болмайды.
- Әр жауап мәтін және/немесе JPEG/PNG/WebP сурет болуы мүмкін (сурет ≤2,7 МБ). Мұғалім әр жауапқа **0–10** ұпай және пікір жазады. Жалпы ұпайлар автоматты түрде қосылып, командалар рейтингіне түседі.
- RU/ҚАЗ тілі сайттың жоғарғы оң жағында ауыстырылады. Тапсырманы тек бір тілде енгізуге де болады: бос тіл үшін мәтін екінші тілден алынады.

## Сабақ кезінде қалай қолданады?

1. Мұғалім басты беттегі **атауды басып**, парольмен кіреді.
2. **«Тапсырмалар»** → 1-команда → бірнеше тапсырманы енгізеді → басқа командаларды толтырады → **«Барлық өзгерісті сақтау»**.
3. **«Басты бет» → «Тестті бастау»**. Мұғалім 20 сұрақтың бәріне жауап береді. Нәтижесі мен дұрыс жауаптары шығады.
4. **«Студенттерге тапсырма ашу»** батырмасын басады.
5. Студенттер бір ортақ сілтеме/QR арқылы кіреді, аты-жөні мен команда кодын енгізеді. Әр команда жауаптарын ретімен жібереді.
6. Мұғалім **«Жауаптар мен бағалар»** бөлімінен әр жауапты тексеріп, баға қояды. Жалпы рейтинг автоматты есептеледі.
7. Келесі сабаққа қажет болса **«Баптаулар» → «Жаңа кезең»**. Бұрынғы жазбалардың мәтіні мен ұпайы архивте қалады, тапсырмалар қайта қолдануға сақталады.

## Render жүйесіндегі бұрынғы сайтты қалай жаңарту керек?

GitHub-тың `https://github.com/gazizsetly-afk/economic-relay` репозиторийін қолданыңыз.

1. Осы архивті ашып, оның **ішіндегі файлдарды** GitHub-қа **Add file → Upload files** арқылы жүктеңіз. Файл атаулары бірдейлер жаңасымен **ауыстырылуы** тиіс. ZIP-тің өзін GitHub-қа салмаңыз.
2. GitHub-та `index.html`, `styles.css`, `app.js`, `server.js`, `package.json`, `.node-version` және басқа файлдар **бір түбірлік папкада** көрінуі тиіс (`tests/` папкасы бөлек болуы мүмкін).
3. **Commit changes** басыңыз.
4. Render → бұрынғы `economic-relay` Web Service → **Deploys**. Автоматты деплой өтпесе **Manual Deploy → Deploy latest commit**. Build `npm install`, Start `npm start`, Node 22.16.0.
5. Жасыл **Live** шыққанда бұрыннан бар `https://economic-relay.onrender.com` сілтемесімен ашыңыз. **Сілтеме өзгермейді**, жаңасын құрудың қажеті жоқ.
6. Environment ішінде бұрынғы **TEACHER_PASSWORD**, **SESSION_SECRET** сақталсын (оларды GitHub-қа салмаңыз). Міндетті түрде тұрақты сақтау орны **DATABASE_URL** болсын.

### База туралы маңызды ескерту

**Render Free-де деректердің локалды сақталуы сенімсіз:** қайта деплойдан немесе сервер қайта іске қосылғаннан кейін JSON файлы өшуі мүмкін. Нақты сыныппен пайдаланғанда **PostgreSQL** қосыңыз, мысалы [Neon](https://console.neon.tech/) және `DATABASE_URL` мәнін Render → Environment ішінде баптаңыз. Жобаның `/health` адресі `storage: "postgres"` көрсетсе, тұрақты база қосылған. Render PostgreSQL және Neon жоспарларын, дерек сақтау лимиттерін өзіңіз тексеріңіз. Егер жаңартудан бұрын деректер Render-дің уақытша локалды файлына ғана сақталған болса, оларды қайтаруға кепілдік жоқ.

**Деректерді жаңарту:** v2 деректер базасы PostgreSQL-ге қосулы болса, v3 алғаш іске қосылғанда бұрынғы бір тапсырма/жауапты жаңа көп-тапсырмалы форматқа автоматты көшіреді. Құпия SESSION_SECRET мәнін өзгертпеу керек, әйтпесе командалық PIN-кодтарды қалпына келтіру қиын болуы мүмкін. Жаңартудан бұрын мұғалім кабинетіндегі **JSON резервтік көшірмені** жүктеп алу ұсынылады.

## Windows-та жергілікті тексеру

1. Node.js 22 орнатыңыз.
2. `.env.example` файлының көшірмесін `.env` деп сақтаңыз. Ішіне құпия `TEACHER_PASSWORD`, `SESSION_SECRET` жазыңыз, `DATABASE_URL` мәнін локалды тест үшін бос қалдырыңыз.
3. Терминалда `npm install` және `node --env-file=.env server.js` орындаңыз.
4. `http://localhost:3000` сайтына кіріңіз. Жергілікті QR басқа телефондарда жұмыс істемеуі мүмкін — ортақ сілтеме үшін Render керек.

## Код құрылымы және тесттер

- `server.js`: авторизация, мұғалім мен студент API, тапсырма кезегі, бағалар, JSON/PostgreSQL сақтау, суреттер, QR.
- `index.html`, `styles.css`, `app.js`: жеңілдетілген екі тілдегі дизайн және интерактивті интерфейс.
- `.node-version`: Render Node 22.16.0.
- `tests/*.test.js`: `npm test` — мұғалім тесті, 7 команда, 3 тапсырма, автоматты ашылу, фотоның құпиялығы, баға және миграция тексерістері.

**Қауіпсіздік:** PIN-дерді әр командаға бөлек беріңіз. Оқушының аты мен фотосын қолдануға оқу орнының ережелеріне сәйкес рұқсат алыңыз. Мұғалім құпиясөзін, PostgreSQL сілтемесін, SESSION_SECRET-ті жарияламаңыз. Көбірек деректі сақтау үшін тұрақты базаның лимитін және резервтік көшірмені қадағалаңыз.
